# 🧪 ProBike Gym — Test Matrix & Verification Scenarios (`TEST_PLAN.md`)

> **قاعدة صارمة:** أي مهمة مرتبطة باختبار معين في `docs/gym/TASKS.md` يجب تشغيل اختبارها والتحقق من النتيجة قبل تحويل المهمة إلى `DONE`.

---

## 🔬 المستويات الأربعة للاختبار

1. **Unit Tests (`test/gym/unit/`):** منطق الحسابات، خوارزمية Ghost Pre-fill، أوزان الطارات، تحويل الوقت الرتيب.
2. **Widget Tests (`test/gym/widget/`):** أزرار الزيادة السريعة، تبديل Explore/Orbit mode، كروت التمارين.
3. **Integration Tests (`test/gym/integration/`):** مسار إضافة Set، تحديث الداتابيز، وتوليد سجل التمرين.
4. **iPhone Manual Scenarios:** اختبارات الجهاز الفعلي (الـ 3D، استهلاك البطارية، والجزيرة التفاعلية Dynamic Island).
